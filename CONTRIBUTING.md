# Contributing to RepoBuddy

Thanks for helping make repository maintenance easier!

1. Search the issues first; open an issue to discuss large changes.
2. Fork the repository and create a descriptive branch.
3. Install locally with `python -m pip install -e .`.
4. Add or update tests for behavior changes, and run `python -m pytest -q` (install pytest first).
5. Open a pull request explaining the motivation, behavior and tests.

Keep changes focused, friendly, and beginner-accessible. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). For vulnerabilities, use [SECURITY.md](SECURITY.md) instead of a public issue.
