# Publier RepoBuddy sur GitHub — Guide débutant

Le projet RepoBuddy est publié à l'adresse :
https://github.com/lefebvreperrottearthur-stack/RepoBuddy

## Utilisation

Clonez le dépôt, installez Python 3.10 ou plus récent puis exécutez :

```bash
python -m pip install -e .
python -m pytest -q
repobuddy .
```

## Suivi du projet

- Vérifiez l'onglet **Actions** : les tests doivent passer.
- Dans le dépôt, ajoutez une description et des thèmes (ex. `python`, `cli`, `open-source`, `developer-tools`).
- Dans **Settings > Security**, activez si possible le signalement privé des vulnérabilités.
- Créez des issues pour les futures fonctionnalités afin d'accueillir des contributeurs.
