# Security Policy

## Supported versions

Security fixes currently target the latest version on the main branch.

## Reporting a vulnerability

Please **do not** open a public issue for a potential vulnerability. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature when enabled in the repository's Security settings. If unavailable, contact the maintainer privately using a contact method published on their GitHub profile.

Do not share private keys, tokens or third-party data in reports. RepoBuddy provides basic filename heuristics, not a comprehensive credential scanner.
